# JsonPowerDB Web Form Project

## Description
This project is simple web form using HTML and JsonPowerDB. It is made as part of a course provided by Login2Explore company. The main goal of this project is to learn how to connect frontend with database using JsonPowerDB.

In this project, we use HTML, JavaScript and AJAX to send and get data from server without reloading page :contentReference[oaicite:0]{index=0}. It helps to understand basic working of web forms and database connection.

This project is not very advanced, it is mainly for learning and practice purpose.

## Benefits of using JsonPowerDB
- It is easy to use and setup is very simple  
- It is fast and works well with JSON data  
- No need to create complex backend  
- It support API based working  
- Good for beginners and small level project  
- Less coding required  

---

## Scope of functionalities
- Create simple employee form  
- Take input like id, name and email  
- Validate input fields  
- Send data to JsonPowerDB  
- Use AJAX for background request  
- Reset form after saving  

---

## Examples of use
User will enter data in form like:

- Employee ID  
- Employee Name  
- Email  

After clicking save button, data is stored in database.  
If any field is empty then it will show alert message.
